# 커밋 메시지 생성

변경 사항을 분석하여 커밋 메시지를 작성합니다.

## 수행 단계

1. **변경 사항 확인**

   - `git diff --staged` 또는 `git diff`로 변경 내용을 확인합니다

2. **커밋 메시지 작성**
   - Conventional Commits 형식을 사용합니다
   - 변경 유형과 범위를 파악합니다
   - 간결하고 명확한 메시지를 작성합니다

## 커밋 메시지 형식

```
<type>(<scope>): <subject>

<body>
```

### Type

- `feat`: 새 기능입니다
- `fix`: 버그 수정입니다
- `refactor`: 리팩토링입니다
- `docs`: 문서 변경입니다
- `test`: 테스트 추가/수정입니다
- `chore`: 빌드, 설정 변경입니다

### 예시

```
feat(auth): 로그인 API 추가

- JWT 토큰 발급을 구현합니다
- 리프레시 토큰 로직을 추가합니다
```

## 인자

- `$ARGUMENTS`: 추가 컨텍스트입니다 (선택사항)

## 예시

```bash
/commit                    # staged 변경사항으로 메시지를 생성합니다
/commit 로그인 기능 완료    # 컨텍스트를 추가합니다
```
