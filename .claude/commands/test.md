# 테스트 실행

테스트를 실행하고 결과를 분석합니다.

## 수행 단계

1. **테스트 실행**
   - **test-runner** 서브에이전트를 사용하여 테스트를 실행합니다

2. **결과 분석**
   - 실패한 테스트의 원인을 분석합니다
   - 커버리지 리포트를 확인합니다

3. **개선 제안**
   - 테스트 커버리지 개선점을 제안합니다
   - 누락된 테스트 케이스를 식별합니다

## 인자

- `$ARGUMENTS`: 테스트할 특정 파일, 디렉토리, 또는 테스트 패턴입니다

## 예시

```bash
/test                      # 전체 테스트를 실행합니다
/test src/utils           # utils 디렉토리를 테스트합니다
/test --coverage          # 커버리지를 포함하여 실행합니다
/test auth.test.ts        # 특정 테스트 파일을 실행합니다
```
