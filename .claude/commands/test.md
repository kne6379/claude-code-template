# 테스트 실행

테스트를 실행하고 결과를 분석합니다.

## 수행 단계

1. **테스트 실행**
   - **test-runner** 서브에이전트를 사용하여 테스트 실행

2. **결과 분석**
   - 실패한 테스트 원인 분석
   - 커버리지 리포트 확인

3. **개선 제안**
   - 테스트 커버리지 개선점 제안
   - 누락된 테스트 케이스 식별

## 인자

- `$ARGUMENTS`: 테스트할 특정 파일, 디렉토리, 또는 테스트 패턴

## 예시

```bash
/test                      # 전체 테스트 실행
/test src/utils           # utils 디렉토리 테스트
/test --coverage          # 커버리지 포함 실행
/test auth.test.ts        # 특정 테스트 파일 실행
```
