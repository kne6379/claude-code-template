# 문서화 생성

코드에 대한 문서를 자동으로 생성합니다.

## 수행 단계

1. **코드 분석**
   - 지정된 파일 또는 모듈 구조를 분석합니다
   - 함수, 클래스, 인터페이스를 식별합니다

2. **문서 생성**
   - API 문서를 생성합니다
   - 사용 예시를 작성합니다
   - 타입 정의를 문서화합니다

3. **README 업데이트**
   - 필요 시 README.md 업데이트를 제안합니다

## 인자

- `$ARGUMENTS`: 문서화할 파일 또는 디렉토리입니다

## 예시

```bash
/document src/api         # API 디렉토리를 문서화합니다
/document src/utils/date.ts  # 특정 파일을 문서화합니다
/document --readme        # README.md를 업데이트합니다
```

## 출력 형식

- JSDoc/TSDoc 형식의 인라인 문서를 생성합니다
- 필요 시 Markdown 형식의 외부 문서를 생성합니다
